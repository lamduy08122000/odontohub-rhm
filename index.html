Quy trình nạp bài giảng mới vào file lessons.js

1. Cấp quyền cho đồng nghiệp trên GitHub

Vào kho GitHub → Settings → Collaborators → Add people để mời tài khoản GitHub của đồng nghiệp cùng chỉnh sửa file lessons.js.

2. Trích xuất bài học từ file sách PDF bằng AI

Tải file sách PDF lên Gemini/Claude, chỉ định số trang và yêu cầu xuất đoạn mã theo đúng cấu trúc mảng LESSONS trong file lessons.js.

3. Dán vào lessons.js → Tự động cập nhật

Mở file lessons.js trên GitHub, dán bài mới vào danh sách và bấm Commit changes. Trang Vercel sẽ tự cập nhật sau 10 giây.
